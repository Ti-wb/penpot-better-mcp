# 驗收流程

依此版本 README 建立可拋棄的 fixture 或明確指定的專用測試檔。站點與連線設定放在私人 `.env`；manifest、session 與原始報告保存在已忽略的本機目錄。

驗收應檢查 MCP 初始化、工具清單、檔案與頁面目標、原生圖形讀寫、匯出、儲存後冷重開、同檔排程、跨檔操作及故障恢復。僅清理該次測試建立的圖形與頁面。

依此版本提供的測試指令檢查認證、逾時、資源回收與錯誤遮罩。工具執行回覆與資料已儲存須分別確認；不應自動重送結果未知的寫入。

部署版本、主機規格、操作時間、原始量測及部署狀態不保存在 Git。測試結果只代表當次負載，不能推論所有 API、授權情境或長期運作均已驗證。
